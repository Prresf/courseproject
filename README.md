# Тортики от Юлии

Веб-сайт кондитерской «Тортики от Юлии» (г. Пинск) — курсовой проект по дисциплине «Веб-технологии и веб-дизайн».

## Технологии

- HTML5 (семантическая разметка, валидация W3C)
- CSS3 + SCSS (препроцессор, адаптивная вёрстка, медиа-запросы)
- JavaScript (DOM-манипуляции, корзина, каталог, фильтрация)
- SVG (векторные иконки, логотип)
- XML + XSLT (каталог товаров)

## Структура проекта

```
site/
  index.html        — главная страница
  catalog.html      — каталог товаров
  product.html      — карточка товара
  cart.html         — корзина
  checkout.html     — оформление заказа
  about.html        — о кондитерской
  css/
    style.scss      — исходные стили SCSS
    style.css       — скомпилированный CSS
    style.css.map   — source map
  js/
    main.js         — клиентский JavaScript
  data/
    products.xml    — каталог товаров в формате XML
    products.xsl    — XSL-преобразование
  svg/
    icons.svg       — спрайт SVG-иконок
docs/
  Пояснительная_записка.docx            — пояснительная записка к курсовому проекту
  Задание на курсовое проектирование.doc — задание на курсовое проектирование
```

## Запуск локального сервера

Установите зависимости и запустите dev-сервер:

```bash
cd site
npm install
npm start
```

Сайт будет доступен по адресу `http://localhost:8080`.

## Компиляция SCSS

```bash
cd site
npm run build:css
```
